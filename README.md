# Keyboard Sounds

A desktop app that plays a sound on every key press, in every app. Choose from phone dial tones, mechanical switches, a typewriter, piano, drums, laser blasts, a shotgun and more, or record your own. It runs quietly in the system tray.

## Features

- **16 built-in sound packs**, all synthesized from scratch: Dial Pad, Mechanical, Typewriter, Piano, Harmonium, Marimba, Drum Kit, Pew Pew, Shotgun, Ninja Swoosh, Retro Coin, 8-bit Jump, Bubble Pop, Boing, Squeaky Toy and Bonk. Chaos mode picks a random pack for every key.
- **Song mode.** Each key press plays the next note of a song (Für Elise, Ode to Joy, In the Hall of the Mountain King and others), so anything you type performs it.
- **Melody and Wobble modes.** Melody turns the keyboard into a pentatonic instrument; Wobble adds a slight random detune.
- **Sustain and echo.** Hold a key and tonal packs keep sounding, then fade out when you let go; taps sound as usual. An optional echo makes every sound trail off in fading repeats.
- **3D stereo.** Keys on the left of the keyboard play in your left ear, keys on the right in your right.
- **On-screen effects.** Bullet holes, lasers, musical notes, confetti, bubbles and blade slashes appear where you type, with a combo meter and milestone banners.
- **Per-app sounds.** Use a different pack in each app, or mute specific apps.
- **Auto-mute** while your microphone is in use (calls, meetings) or a full-screen app is open.
- **Your own packs.** Import audio files or record with your microphone, then share the pack as a single `.kbpack` file that opens straight into the app.
- **Key mapping.** Give Enter, Space, Backspace, letters, numbers, modifiers, arrows or mouse clicks their own sound, plus optional key-release sounds.
- **Typing stats.** Keys per day, words per minute, streaks, a key heatmap and 18 achievements.
- Tray menu, a global mute shortcut (`Ctrl + Alt + M`), start with your computer, and automatic updates.

## Download

Get the latest installer from the [Releases](../../releases) page.

| Platform | File |
| --- | --- |
| Windows 10/11 | `Keyboard-Sounds-Setup-<version>.exe` |
| macOS (Apple silicon / Intel) | `Keyboard-Sounds-<version>-arm64.dmg` / `-x64.dmg` |
| Linux | `Keyboard-Sounds-<version>.AppImage` |

The builds are not code-signed yet:

- **Windows** may show “Windows protected your PC”. Choose **More info → Run anyway**.
- **macOS** may say the app is damaged. Move it to Applications and run `xattr -cr "/Applications/Keyboard Sounds.app"`. Then allow it under **System Settings → Privacy & Security → Accessibility** so it can hear the keyboard.
- **Linux** needs an X11 session; Wayland does not allow global key hooks.

## Privacy

Keyboard Sounds needs to see key presses to play sounds. It stores only how many times each key was pressed, for the Stats page. It never stores what you type or the order of keys, and it sends nothing anywhere except the update check to GitHub. Everything stays in your user data folder (`%APPDATA%\Keyboard Sounds` on Windows).

Windows does not let apps hear keys typed into programs running as Administrator unless they also run as Administrator.

## Development

Requires Node.js 22.12 or newer.

```bash
npm install
npm start          # generates sounds and icons, then launches the app
npm test           # unit tests (node:test)
npm run lint
npm run dist       # builds an installer for the current platform into dist/
```

`assets/sounds/` and `build/icon.png` are generated by `npm run assets` and are not committed.

### Project structure

```
scripts/                 sound synthesis, icon rendering, catalog check, icon vendoring
src/
  shared/                code used by every process: constants, catalog, songs, icons, types
  preload.cjs            the IPC bridge exposed to windows as window.api
  main/                  Electron main process
    index.js             startup wiring and app lifecycle
    core/                pure logic, unit-tested: key mapping, stats, achievements, pack format
    settings/            settings schema, validation, migration and persistence
    services/            OS integration: keyboard hook, active app, microphone, updates, sound library
    windows/             audio, dashboard and overlay windows, tray
    app/                 orchestration: playback, app context, packs, notifications, IPC handlers
  renderer/
    audio/               hidden Web Audio engine
    overlay/             transparent on-screen effects
    dashboard/           settings UI (pages, components, store)
test/                    unit tests
```

### How it works

The main process installs a system-wide keyboard hook ([uiohook-napi](https://github.com/SnosMe/uiohook-napi)). For each key press, `KeyMapper` decides which sample to play and at what pitch and stereo position, and sends that to a hidden window, where the Web Audio API plays it with low latency through a limiter. Effects are drawn on one transparent, click-through window per display. On Windows, [koffi](https://koffi.dev) is used to read the active app, full-screen state and text-caret position.

### Adding a built-in pack

1. Add a recipe to `scripts/generate-sounds.js` that writes the pack's WAV files.
2. Add the pack to `src/shared/catalog.js`, picking an icon from `src/shared/icons.js`. To use a new Lucide icon, add its name to `scripts/vendor-icons.js` and run `npm run icons:vendor`.
3. Run `npm run assets && npm run check`.

### Releasing

1. Set `"repository"` in `package.json` to your GitHub repository.
2. Update the version in `package.json` and add an entry to `CHANGELOG.md`.
3. Commit, then push a tag: `git tag v1.0.0 && git push --tags`.
4. The Release workflow builds Windows, macOS and Linux installers and attaches them to a draft release. Publish the draft; installed copies pick up the update automatically.
